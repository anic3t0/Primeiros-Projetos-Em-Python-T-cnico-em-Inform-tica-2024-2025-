# Primeiros Projetos de Programação — Técnico em Informática

## Sobre
Este repositório reúne alguns dos primeiros códigos que desenvolvi durante o curso Técnico em Informática, entre 2024 e 2025.

Os projetos representam meu primeiro contato com programação e foram desenvolvidos ao longo das disciplinas e atividades práticas do curso. A maior parte dos códigos deste repositório foi desenvolvida em Python, além de alguns projetos em C++ que serão adicionados posteriormente.

Os códigos foram mantidos como parte do meu histórico de aprendizado, permitindo acompanhar minha evolução desde exercícios básicos de lógica de programação até projetos um pouco mais estruturados.

## Conteúdo
- Lógica de programação
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Manipulação de dados
- Interfaces gráficas
- Exercícios e pequenos projetos

## Projetos
| Projeto | Descrição |

| `interface.py` | Criação de uma interface gráfica simples, com uma janela contendo botões e comandos básicos de interação. |

| `baskara.py` | Cálculo da fórmula de baskara. |

| `imc.py` | Calculadora de Índice de Massa Corporal (IMC). |

| `multiplicação.py` | Programa para realizar operações de multiplicação. |

| `positivo ou negativo.py` | Verifica se um número é positivo ou negativo. |

| `soma +3.py` | Exercício com operações matemáticas simples e entrada de dados. |

| `média bimestral.py` | Calcula a média de notas bimestrais. |

| `jogo.py` | Jogo de adivinhação de palavras, com níveis de dificuldade, número limitado de tentativas e dicas. |

| `jogo da forca.py` | Implementação de um jogo da forca. |

| `telа imc.py` | Aplicação gráfica do cálculo do IMC, incluindo campos para dados, exibição do resultado e um menu com opções de ajuda e navegação entre telas. |

## Observação
Este repositório não representa necessariamente meu nível atual de programação, ele funciona como um registro dos meus primeiros passos na área e da evolução obtida ao longo da formação técnica.
